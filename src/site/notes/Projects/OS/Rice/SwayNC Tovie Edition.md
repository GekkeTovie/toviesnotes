The original October 2025 setup replaced Mako with SwayNotificationCenter (SwayNC), added a sixth workspace for the three-monitor desktop, and put notification status where the network widget had been. The Hyprstellar theme, a palette generated by pywal, and a Nerd Font supplied the finishing touches.

<span id="chapter-i-replacing-the-sprite-mako-sway-nc"></span>

## Switch the notification daemon

Find where your session starts Mako. It might come from your compositor configuration, the desktop preset, or a user service. Switch that launch entry to SwayNC and sign out and back in. If SwayNC already starts through your session manager, use that entry. Both daemons want to handle the same desktop notification service.

The original setup used Hyprland's `exec-once = swaync` syntax. In a Hyprland Lua configuration, the matching startup hook looks like this. [Hyprland autostart](https://wiki.hypr.land/configuring/core/autostart/)

```lua
hl.on("hyprland.start", function()
    hl.exec_cmd("swaync")
end)
```

Before changing Waybar, test the notification by sending `notify-send "SwayNC test" "Open the control center to find this message"` and open the panel with `swaync-client -t`. This isolates notification delivery from the status-bar configuration. [SwayNotificationCenter](https://github.com/ErikReider/SwayNotificationCenter#run)

<span id="chapter-ii-forging-the-sixth-sigil-workspaces-for-3-screens"></span>

## Put six workspaces on the bar

The rice made workspaces `1` through `6` visible in Waybar. Add them to `persistent-workspaces` under `hyprland/workspaces` if you want their buttons to remain visible when empty. An empty output list shows an entry on every output. Use specific output names if you want a button to appear only on particular bars. Set the corresponding workspace placement and persistence in Hyprland. Waybar controls the displayed buttons and Hyprland manages the workspaces. [Waybar workspace options](https://github.com/Alexays/Waybar/blob/master/man/waybar-hyprland-workspaces.5.scd) · [Hyprland workspace rules](https://wiki.hypr.land/0.56.0/Configuring/Basics/Workspace-Rules/)

<span id="chapter-iii-teaching-waybar-to-wink-notifications-on-the-right"></span>

## Connect the notification indicator

Add `custom/notification` to the existing `modules-right` array. Merge the example below into your Waybar config and keep the other modules. The matching state names come from SwayNC. The labels here use ordinary text so you can check each state before switching to your preferred glyphs. [SwayNC Waybar example](https://github.com/ErikReider/SwayNotificationCenter#waybar-example)

```json
{
  "custom/notification": {
    "format": "{icon}",
    "format-icons": {
      "notification": "Alerts •",
      "none": "Alerts",
      "dnd-notification": "DND •",
      "dnd-none": "DND",
      "inhibited-notification": "Paused •",
      "inhibited-none": "Paused",
      "dnd-inhibited-notification": "DND + paused •",
      "dnd-inhibited-none": "DND + paused"
    },
    "return-type": "json",
    "exec-if": "command -v swaync-client",
    "exec": "swaync-client -swb",
    "on-click": "swaync-client -t -sw",
    "on-click-right": "swaync-client -d -sw",
    "escape": true
  }
}
```

## Apply the palette and fonts

The original Waybar stylesheet imported the `colors-waybar.css` generated by pywal. If your setup still uses `wal`, generate the palette from a still image and check that the file exists before adding the import. The path in this example is relative to `~/.config/waybar/style.css`. A stylesheet elsewhere needs its own relative path. If the text labels work and the glyphs show as squares, check the font family selected for that module with `fc-match`.

```css
@import '../../.cache/wal/colors-waybar.css';
```

## Check each layer separately

1. Send a notification and check that SwayNC displays it before changing the bar. If it never arrives, inspect the active daemon and autostart entry.
2. Open and close the panel from Waybar, then toggle Do Not Disturb. Verify the indicator reflects each state. The bubble appearing and the icon changing are separate checks.
3. Check workspaces across all three displays, including an empty one. Check placement in Hyprland if the workspace appears on a different display than intended.
4. Reload SwayNC's settings with `swaync-client -R` and its stylesheet with `swaync-client -rs`. Reload Waybar after changes to its own configuration. `SIGUSR2` reloads Waybar by default, and the action can be overridden. [SwayNC reload options](https://github.com/ErikReider/SwayNotificationCenter#run) · [Waybar signals](https://github.com/Alexays/Waybar/blob/master/man/waybar.5.scd.in#signals)
