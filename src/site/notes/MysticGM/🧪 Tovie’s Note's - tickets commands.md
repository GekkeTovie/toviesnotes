# 🎫 MysticGM – Tickets Playbook

_Ticket lifecycle, panels, and transcripts._

---

## ✨ What’s inside?
- Multi-action ticket command (open/close/assign/add/remove/status).
- Panels to let members start tickets.
- Transcript routing to forums.

## ⚡ Quickcast
- `/ticket` — Open/close/assign/add/remove/status.
- `/ticket post-panel` — Drop the interactive panel.
- `/ticket save-transcript` — Save to the configured forum.

## 🧭 Deep page – All commands
**Slash**
- `/ticket` — Open/close/assign/add/remove/status for tickets.

**Group: `/ticket ...`**
- `post-panel` — Post a ticket panel (staff only).
- `set-transcript-forum` — Set the forum channel for ticket transcripts (admin only).
- `save-transcript` — Save the current ticket's transcript to the configured forum (staff only).
