# 🧭 MysticGM – General Toolkit

_Everyday sigils: info snapshots, reminders, text wrangling, conversions._

---

## ✨ What is this?
- Bot/server/user info at a glance.
- Randomizers, reminders, text transforms.
- Conversions (counts, numbers, colors, timestamps) and misc helpers.

## 📚 Contents (pick your utility)
- **Info:** `bot`, `user`, `server`, `message`
- **Helpers:** `convert`, `text`, `utility`
- **Ops:** `random`, `reminder`

## 🧭 How to Navigate
- Start with `/general bot` for heartbeat checks.
- Use `/general reminder` to loop back to `/general message` jump links.
- Keep `/general convert` handy for quick math/colors/time.

## 🪄 Command Grimoire — `/general ...`
- `bot` — Bot utilities (ping, uptime, info, invite, support).
- `user` — User utilities (info, avatar, banner).
- `server` — Server utilities (info, stats, assets).
- `random` — Randomization tools (coinflip, pick, shuffle).
- `text` — Text utilities (transformations and formatting).
- `convert` — Conversion helpers (counts, numbers, colors, timestamps).
- `message` — Message lookups (first, last, info, jump).
- `reminder` — Reminder manager (create, list, cancel).
- `utility` — Misc utilities (calc, time, poll, say, emojiinfo).

> **Tip:** Bookmark `/general reminder` + `/general message` as your “follow-up” ritual.
