# 🧮 MysticGM – Leveling Codex

_XP tracking, level roles, alerts, and leaderboards._

---

## ✨ What’s inside?
- Rank lookups, leaderboards, and level-up alerts.
- Auto role generation and role-channel targeting.

## ⚡ Quickcast
- `/leveling rank` — Detailed XP/level breakdown.
- `/leveling leaderboard` — Leaderboard with filters.
- `/leveling set-levelup-channel` — Target channel for level-up alerts.

## 🧭 Deep page – All commands
**Group: `/leveling ...`**
- `rank` — Check your or another user's rank and XP stats.
- `levelrole` — Manage level role rewards.
- `set-levelup-channel` — Set the channel for level-up alerts (requires Manage Guild).
- `create-level-roles` — Generate level reward roles for a range.
- `create-level-roles-steps` — Generate level roles with stepped or scaled spacing.
- `leaderboard` — View the XP leaderboard with filters.
